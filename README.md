# Китайский с героем

Тренажёр китайского языка для Демида.

**Открыть:** https://aleksarulezzz.ru/chineese/

- `index.html` — весь тренажёр (одна страница). Опубликован в репозитории `site-lashmaker` в папке `chineese/`.
- Прогресс хранится в браузере устройства. Резервная копия: Настройки → «Сохранить в файл».
- `server.py` и `Запустить тренажер.command` — старый способ запуска на Mac через localhost:8765 (необязателен).
