# Китайский с героем 🏮

Тренажёр китайского языка для Демида.

**Открыть тренажёр:** https://aleksarulezzz.ru/chineese/

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь тренажёр: одна страница со словами, уроками, героями и прогрессом. **Чтобы поменять тренажёр, достаточно заменить этот файл.** Через 1–2 минуты GitHub Pages обновит сайт. |
| `manifest.webmanifest`, `icons/`, `sw.js` | Установка на телефон как приложение и работа без интернета. Инструкция для посетителей: «Родителям» → «Как устроен тренажёр» → «Установить на телефон». |
| `og.png` | Картинка превью, когда ссылкой делятся в мессенджерах |
| `mic-test.html` | Старая ссылка на проверку микрофона, перенаправляет на тренажёр |
| `server.py` | Локальный сервер для запуска на Mac без интернета (необязательно). |
| `Zapustit-trenazher.command` | Запуск на Mac через localhost:8765 (необязательно). Перед первым запуском выполните `chmod +x Zapustit-trenazher.command`. |

## Прогресс

- На сайте прогресс хранится в браузере того устройства, где занимается Демид.
- Резервная копия: в тренажёре «Настройки» → «Сохранить в файл». Восстановление: «Загрузить из файла».
- Файл `progress.json` с прогрессом в этот репозиторий **не выкладывается**: репозиторий публичный.

## Публикация

Сайт публикует GitHub Pages прямо из этого репозитория (ветка `main`, корень). Адрес `aleksarulezzz.ru/chineese/` совпадает с именем репозитория, а домен привязан к главному сайту `aleksarulezzz-lab.github.io`.
