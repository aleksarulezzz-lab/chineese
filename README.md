# Китайский с героем 🏮

Тренажёр китайского языка для Демида.

**Открыть тренажёр:** https://aleksarulezzz.ru/chineese/

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь тренажёр: одна страница со словами, уроками, героями и прогрессом. **Чтобы поменять тренажёр, достаточно заменить этот файл.** Через 5–10 минут изменения появятся на сайте. |
| `site-loader/index.html` | Копия маленькой страницы-указателя, которая лежит в репозитории `site-lashmaker` в папке `chineese/`. Она нужна только потому, что домен aleksarulezzz.ru привязан к `site-lashmaker`. Указатель берёт `index.html` из этого репозитория и хранит его копию в браузере. |
| `server.py` | Локальный сервер для запуска на Mac без интернета (необязательно). |
| `Zapustit-trenazher.command` | Запуск на Mac через localhost:8765 (необязательно). Перед первым запуском выполните `chmod +x Zapustit-trenazher.command`. |

## Прогресс

- На сайте прогресс хранится в браузере того устройства, где занимается Демид.
- Резервная копия: в тренажёре «Настройки» → «Сохранить в файл». Восстановление: «Загрузить из файла».
- Файл `progress.json` с прогрессом в этот репозиторий **не выкладывается**: репозиторий публичный.
